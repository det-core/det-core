## About

I'm a developer focused on building **reliable software, practical systems, and clean developer experiences**.

My interests span full-stack development, backend engineering, REST APIs, Linux environments, automation, and software architecture.

I prefer understanding systems at a deeper level — how components communicate, how applications scale, where failures occur, and how software can be designed to remain maintainable as it grows.
